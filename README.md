# 🍗 Tiệm Gà Nhà Tui (My Fried Chicken Shop)

> Game web mô phỏng quản lý quán gà rán Sài Gòn phong cách 2D Sticker Retro Chibi ấm áp, tương tác 1 ngón cái cực mượt!

🎮 **Chơi Game Trực Tiếp Tại**: [https://tandung060604-prog.github.io/tiem-ga-nha-tui/](https://tandung060604-prog.github.io/tiem-ga-nha-tui/)

---

## 🌟 Điểm Nổi Bật (Phiên Bản v2.2.1)

* 🍲 **Pha Nước Sốt Bí Truyền (Sáng Sớm)**: Minigame ghi nhớ 5 gia vị gia truyền, kích hoạt Buff Vàng +3.000đ tip/đơn và bảo hộ +0.25★ Hương Vị.
* 🍗 **Bếp Chiên Gà Realtime (Trong Ngày)**: Chạm canh chuẩn 5 nấc nhiệt độ (Sống $\rightarrow$ Tái $\rightarrow$ Hoàn Hảo $\rightarrow$ Vàng Giòn $\rightarrow$ Cháy Khét), chuỗi streak hoàn hảo bốc lửa.
* 🧹 **Lọc Cặn Dầu & Vớt Bột Cháy (Đêm Muộn)**: Minigame 15s cứu chảo cháy, phục hồi chất lượng dầu chiên, tiết kiệm ngay 150.000đ chi phí vận hành và bảo hộ điểm Vệ Sinh.
* 👥 **Hệ Thống Thực Khách & Cốt Truyện Hẻm 1102**: 36 cư dân xóm hẻm, Khách Sộp VIP viền vàng, 25 sự kiện kịch tính bất ngờ và 5 đại kết cục phân nhánh.
* 👮‍♂️ **Pháp Lý ATVSTP 3 Strikes**: Đội kiểm tra Quản Lý Thị Trường ập vào kiểm tra khi dùng dầu đen độc hại.
* 📱 **Tối Ưu Golden Thumb-Zone**: Vừa vặn 100% trên các dòng smartphone hẹp 360px & 390px, hỗ trợ cài đặt PWA chơi toàn màn hình như native app.

---

## 🛠️ Công Nghệ Phát Triển
* **Core**: TypeScript, Vite, Vanilla CSS Design System (0 dependency CSS nặng).
* **Audio**: Web Audio Synthesizer (tự tổng hợp âm thanh đa tần số, không phụ thuộc file âm thanh ngoài).
* **Kiểm Thử & Đảm Bảo Chất Lượng**: Vitest (462 tests PASS 100%), Puppeteer Headless UI Check, GitHub Actions CI/CD.

---

## 🚀 Chạy Cục Bộ (Local Development)

```bash
# Cài đặt thư viện phụ thuộc
npm install

# Khởi chạy môi trường phát triển
npm run dev

# Chạy toàn bộ kiểm thử
npm test

# Kiểm tra chất lượng giao diện mobile
npm run ui:check

# Đóng gói sản phẩm
npm run build
```
